# Make the Judge Smile — Makefun entry

Competition: https://make.fun/bounty/u-gentle-badger-68-make-the-judge-smile-9228676d

A single line (at most 200 characters) about a small good thing that happened
today, something that would make a reader smile.

## Run

```sh
node main.ts
```

Writes the line to `/output/entry.txt` (or `./output/entry.txt` when `/output`
is not writable, e.g. a local run).

## The line

> At 4 a.m., the warung auntie slipped a still-warm fried banana into my bag and whispered, 'for the road home' — I hadn't even ordered it.
